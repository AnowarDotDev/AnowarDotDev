## anowar.dev — built from scratch

My portfolio isn't a template — it's a full product I designed, built, and operate on my own VPS.

**Stack:** Laravel 13 · Inertia.js · React 19 · TypeScript · Tailwind CSS v4 · SSR · MySQL · Redis · Laravel Octane (RoadRunner)

What's inside:

- 🧩 **Custom admin panel** — ~30 sections: content, analytics, settings, media, menu builder
- 📝 **Blog CMS** — nested categories, full revision history with word-level diff &amp; restore, comment moderation, RSS
- 🤝 **Client portal** — per-client workspace with milestones, PDF invoices, e-signed contracts, real-time chat, payment ledger
- 🎓 **LMS** — courses, batches, lesson player with progress tracking, quizzes, assignments, live sessions, attendance, verifiable certificates
- 🤖 **AI chatbot** — tool-calling agent over my own content, with multi-provider model failover
- ⚡ **Real-time &amp; push** — Laravel Reverb WebSockets + Firebase Cloud Messaging web push
- 🚀 **Performance** — Redis full-page response cache, Octane, image optimization, dynamic OG image generation
- 📡 **SEO &amp; PWA** — sitemap index, structured data, installable PWA with offline fallback
- 🔒 **Security** — rotating secret admin route, honeypot decoys, audit logging, reCAPTCHA, daily security digest
- 🛠️ **CI/CD** — Pest test suite, Pint, PHPStan, ESLint via GitHub Actions; release-triggered zero-downtime VPS deploy
